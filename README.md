# Cognosco

See the whole business from the files a company already keeps.

Cognosco reads sales, stock, payments, bank records, and the staff list. It suggests what each column means, joins the same people and the same items, and shows where money is going. A person confirms the joins and approves the next step. Nothing is replaced.

## Samples

The landing page opens four fictional businesses: a pharmacy and shop, a building-materials distributor, a private clinic group, and a payments business. The records are generated locally. They are not real customers.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
